# Interfacer client SDK documentation

Documentation and examples for [`@dyne/interfacer-client`](https://github.com/interfacerproject/interfacer-client), built with VitePress and TypeDoc.

## Local development

```sh
pnpm install
pnpm docs:dev
```

Build the site with `pnpm docs:build`, generate the API documentation with `pnpm docs:api`, and run the example tests with `pnpm test:examples`.

See [docs/index.md](docs/index.md) for the documentation entry point.
